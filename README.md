# StudyFocus

**Seu tempo. Seu foco. Sua evolução.**

O StudyFocus é uma plataforma gratuita de organização dos estudos, criada como projeto individual para uma feira de ciências.

## Recursos da primeira versão

- **Painel inicial:** resumo de tarefas, tempo de foco, revisões e meta semanal.
- **Tarefas:** cadastro de atividade, matéria, prazo e prioridade; conclusão e exclusão.
- **Temporizador Pomodoro:** ciclos de foco de 25 minutos, pausa curta de 5 minutos e pausa longa de 15 minutos.
- **Revisão ativa:** cartões de pergunta e resposta criados pelo estudante.
- **Progresso:** histórico de sessões, gráfico dos últimos sete dias e meta semanal configurável.
- **Privacidade:** os dados ficam no armazenamento local do navegador (LocalStorage). Não há cadastro nem envio de dados para um servidor.

## Como executar

Abra o arquivo `index.html` em um navegador moderno. Para publicar gratuitamente, habilite o GitHub Pages nas configurações do repositório:

1. Abra **Settings**.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Salve e aguarde a publicação.

O endereço publicado será semelhante a `https://cjulin96-stack.github.io/StudyFocus/`.

## Pesquisa para a feira de ciências

**Pergunta investigativa:** o uso de uma plataforma digital de organização e revisão pode ajudar estudantes a melhorar sua organização e retenção de conteúdos escolares?

Uma avaliação escolar pode comparar uma atividade inicial com outra equivalente após um período de uso, além de observar tarefas concluídas, sessões de estudo e revisões. Os resultados devem ser apresentados com honestidade: uma amostra pequena ou um período curto não prova, por si só, que a plataforma causou uma melhora.

A coleta com estudantes deve ocorrer somente com autorização do professor e os consentimentos necessários. Não registre nomes ou dados pessoais desnecessários.

## Observação sobre os dados

O progresso é salvo apenas no navegador e aparelho usados. Limpar os dados do navegador ou trocar de aparelho pode apagar ou tornar indisponíveis essas informações. Esta versão não sincroniza dados entre dispositivos.
